# 트리아지 (분류 전용)

이 스킬은 **고치지 않고 분류만** 한다. 무엇이 문제인지, 어떤 스킬로 어디를 다룰지를 정해 주는 것이 목적이다.
고치는 일은 추천한 스킬이 한다.

## 진행 순서

1. **증상 확보** — 인자가 있으면 그것, 비어 있으면 무엇이 문제인지(느림·메모리·로그·테스트·구조·문서, 어느 화면/작업)
   **먼저 물어본다.** 저장소 전체를 임의로 훑지 않는다.
2. **규약 확인** — 프로젝트 규약(`CLAUDE.md`·`AGENTS.md`·README)과 실행 환경(메모리 예산·DB·프록시·배포 형태)을 읽는다.
3. **증상을 한 문장으로 다시 쓴다** — "무엇이 / 언제 / 얼마나". 예: "메인 첫 요청 응답 2.1초(로컬 3회 중앙값)".
   - 재현하거나 잴 수 있으면 잰다. 못 재면 **"확인 못 함"** 으로 둔다. 추정을 측정값처럼 쓰지 않는다.
   - 회선이 섞인 외부 측정, 개발 설정(캐시 끔·디버그 로그)이 부풀린 숫자는 분류 전에 걸러낸다.
4. **근거를 코드 사실로 찾는다** — 쿼리 수, 루프 중첩·복잡도(O표기), 자료구조, 보유량, 로그 위치, 테스트 결과, import 방향.
5. **분류하고 추천한다** — 아래 표로.

## 분류표

| 신호 | 추천 스킬 |
|------|-----------|
| 요청당 쿼리가 많다(N+1) · 데이터가 늘수록 느려진다 · CPU·루프·중복 계산 · 특정 함수·화면이 느리다 | `hotspot` |
| OOM · 힙이 계속 는다 · 커넥션/파일/스트림 누수 · 전량 적재 · 끝없이 크는 캐시 | `memory` |
| 느리진 않은데 읽기·고치기 어렵다 · 중복 로직 · 깊은 중첩 · 긴 함수 | `refactor` |
| 핵심 경로라 동작이 한 글자도 바뀌면 안 된다 | `safe` (위 어느 것과도 겹쳐 쓸 수 있다) |
| 장애 원인을 로그로 못 찾는다 · 에러가 안 남는다 · 로그가 너무 많다 · 레벨이 뒤죽박죽 | `logging` |
| 테스트가 깨졌다 · 낡았다 · 건너뛴다 · 커버리지를 모른다 · 테스트가 없다 | `test` |
| 계층이 뒤섞였다 · 도메인이 인프라를 안다 · 순환 참조 · 모듈 경계가 무너졌다 | `arch` |
| API 문서가 없거나 코드와 다르다 · 명세를 HTML 로 발행해야 한다 | `apispec` |
| 문제가 어디인지 넓게 진단부터 받고 싶다(수정 없이) | `review` |

- 여러 신호가 겹치면 **영향도(빈도 × 1회 비용) 큰 것부터** 순서를 매긴다. 드물게 도는 경로의 미세 최적화는 추천하지 않는다.
- 원인이 이 표 밖(인프라 설정·네트워크·외부 서비스 장애 등)이면 그렇다고 말하고, 스킬을 억지로 끼워 맞추지 않는다.

## 원칙

- **코드를 수정하지 않는다.** 설정·테스트·문서도 건드리지 않는다.
- **추정이 아니라 사실로 말한다.** 근거 없는 추천은 넣지 않거나 "미검증 가설"로 명시한다.
- 문제가 확인되지 않으면 **"지금은 손댈 근거가 없다"** 고 말하고 끝낸다. 억지로 추천을 만들지 않는다.

## 최종 리포트 (형식 고정)

**결론 한 줄 + 표**로만 보고한다. 과정 설명·산문 문단을 덧붙이지 않는다.

**결론 한 줄** — 무엇이 문제이고, 어느 스킬로 어디부터 볼지.

| 실행 | 대상 | 결과 | 코드 변경 |
|------|------|------|-----------|
| `/optimize:triage <받은 인자 그대로>` | 증상 1건 / 관련 파일 3개 | 추천 2건 | 없음 (분류 전용) |

| # | 증상 | 근거 (측정·코드 사실) | 추정 원인 | 추천 스킬 | 대상 범위 (인자로 넘길 값) |
|---|------|------------------------|-----------|-----------|----------------------------|
| 1 | 메인 첫 요청 2.1s | `HomeService:42` 루프 안 단건 조회 → 요청당 쿼리 31건 | N+1 | `hotspot` | `src/.../HomeService.java` |

- **바로 실행** — `/optimize:hotspot src/.../HomeService.java`
- 확인 못 함 — 무엇을, 왜(재현 불가·측정 수단 없음)

인자 없이 호출돼 증상을 물어 받았으면 `실행` 칸은 `/optimize:triage (인자 없음 → 증상 질문)`처럼 **실제 판단 기준을 그대로** 적는다.
근거가 없으면 표 대신 "지금은 손댈 근거가 없다" 한 줄로 끝낸다.
